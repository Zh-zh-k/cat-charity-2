# QRKot

QRKot — API-сервис благотворительного фонда поддержки котиков.

Пользователи могут регистрироваться, авторизовываться и делать пожертвования.
Суперпользователи управляют благотворительными проектами и могут просматривать
информацию обо всех пожертвованиях.

## Возможности проекта

- регистрация пользователей;
- авторизация по JWT-токену;
- просмотр списка благотворительных проектов;
- создание пожертвований зарегистрированными пользователями;
- просмотр пользователем собственных пожертвований;
- автоматическое распределение пожертвований между открытыми проектами;
- создание, редактирование и удаление проектов суперпользователем;
- просмотр всех пожертвований суперпользователем;
- запрет удаления пользователей через API.

## Логика инвестирования

Пожертвования автоматически распределяются между открытыми проектами.

Средства направляются в проекты по очереди — начиная с проекта, созданного раньше
остальных.

Если сумма пожертвования превышает необходимую сумму для текущего проекта,
остаток автоматически направляется в следующий открытый проект.

При полном финансировании проекта или полном распределении пожертвования объект
закрывается автоматически.

Для закрытого объекта устанавливаются:

- `fully_invested = true`;
- `close_date`.

## Права доступа

### Анонимный пользователь

Может:

- зарегистрироваться;
- просматривать список благотворительных проектов.

### Зарегистрированный пользователь

Может:

- просматривать проекты;
- создавать пожертвования;
- просматривать только собственные пожертвования.

В информации о собственных пожертвованиях пользователь не видит служебные поля,
связанные с распределением средств.

### Суперпользователь

Может:

- просматривать проекты;
- создавать, редактировать и удалять проекты;
- создавать пожертвования;
- просматривать собственные пожертвования;
- просматривать все пожертвования с полной служебной информацией.

Удаление пользователей через API запрещено.

## Установка

Клонировать репозиторий и перейти в директорию проекта:

```bash
git clone git@github.com:Zh-zh-k/cat-charity-2.git
cd cat-charity-2
```

Создать виртуальное окружение:

```bash
python3 -m venv venv
```

Активировать виртуальное окружение.

Linux/macOS:

```bash
source venv/bin/activate
```

Windows:

```bash
venv\Scripts\activate
```

Установить зависимости:

```bash
pip install -r requirements.txt
```

## Основные эндпоинты

### Аутентификация

- `POST /auth/register` — регистрация пользователя;
- `POST /auth/jwt/login` — получение JWT-токена;
- `POST /auth/jwt/logout` — выход из системы.

### Пользователи

- `GET /users/me` — данные текущего пользователя;
- `PATCH /users/me` — изменение данных текущего пользователя;
- `GET /users/{id}` — получение данных пользователя;
- `PATCH /users/{id}` — изменение данных пользователя.

Эндпоинты удаления пользователей отсутствуют.

### Благотворительные проекты

- `GET /charity_project/` — получить список проектов;
- `POST /charity_project/` — создать проект;
- `PATCH /charity_project/{project_id}` — изменить проект;
- `DELETE /charity_project/{project_id}` — удалить проект.

Создание, изменение и удаление проектов доступны только суперпользователю.

### Пожертвования

- `POST /donation/` — создать пожертвование;
- `GET /donation/my` — получить собственные пожертвования;
- `GET /donation/` — получить список всех пожертвований.

Получение всех пожертвований доступно только суперпользователю.
